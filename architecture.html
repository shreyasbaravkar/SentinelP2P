Core Layer Breakdown

Detailed architectural components powering the detection mechanism.

Layer 01

Data & Fraud Injection Layer

Handled via plant_fraud.py, this layer generates realistic corporate entities using Faker. It deliberately implants 8 structural fraud patterns into relational CSV tables before database ingestion to evaluate detection performance.

plant_fraud.py snippet Python 3.10+ 
def inject_shell_vendor_scheme(df_vendors, df_employees):
    # Matches vendor phone/email directly with active staff records
    compromised = df_employees.sample(n=5)
    df_vendors.loc[0:4, 'contact_phone'] = compromised['phone'].values
    df_vendors.loc[0:4, 'is_shell'] = True
    return df_vendors

Layer 02

Graph Topology & Neo4j Layer

Maps entities as nodes—Employees, Vendors, PurchaseOrders, Invoices, and Contracts—interconnected via directional edges. It enforces strict deterministic compliance through explicit Cypher query rule validations (fraud_checks.py).

Layer 03

Heterogeneous GNN Layer

Utilizes PyTorch Geometric’s HeteroConv and SAGEConv modules. By passing messages across multi-typed relational neighborhoods, the model learns embeddings capable of capturing structural anomalies without manual feature engineering.

PyTorch Geometric Architecture PyTorch 
self.convs = torch.nn.ModuleList([

    }, aggr='sum') for _ in range(3)

Layer 04

Vector RAG Layer

Employs all-MiniLM-L6-v2 sentence transformers alongside the Qdrant vector database. This pipeline maps unstructured invoice line-item descriptions and cross-references them against legal procurement contracts to catch price and scope discrepancies instantly.

Experimental Evaluation

Zero-Shot Generalization (Scheme F6)

Evaluating model robustness against hidden contract breach patterns.

To test how well the GNN architecture handles unseen variants of price inflation, scheme F6 (Rate Mismatch) was intentionally withheld during initial model training. Upon evaluation, the multi-layered HeteroConv pipeline successfully flagged structural topological anomalies with high confidence, demonstrating effective zero-shot transfer learning across enterprise networks.
